# MedAce - Flutter Medical Education App (v2.2.5)

A production-ready Flutter medical education application powered by Master Study LMS. MedAce provides medical students and professionals with courses, video lectures, assignments, and comprehensive learning tools.

## Technologies Used
- Flutter / Dart
- BLoC state management
- Firebase (Core, Messaging, Crashlytics)
- Dio / HTTP networking
- VdoCipher / YouTube / Vimeo video players
- WebView (InAppWebView)
- In-App Purchase
- Google Sign-In / Facebook Auth
- Cached Network Images
- Shimmer loading effects

## Features
- Course catalog with video lectures
- User authentication (email, Google, Facebook)
- Assignment and exam system
- Reviews and ratings
- Favorite courses
- Push notifications
- In-app purchases
- Video playback with multiple providers
- Offline connectivity detection
- Localization support
- Crashlytics error reporting
- Version 2.2.5

Built for MedAce medical education platform.
